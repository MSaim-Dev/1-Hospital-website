## ✨ Features

- **Semantic HTML5** structure — `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`
- **Hero Section** — full viewport background image with dark gradient overlay
- **About Section** — side-by-side layout with stats row (25+ years, 150+ doctors, 50k+ patients)
- **Services Section** — 6 service cards in a CSS Grid layout with hover animations
- **Doctors Section** — 3 doctor profile cards with image zoom on hover
- **Contact Section** — 3-column grid with a dark CTA card
- **Footer** — multi-column layout with quick links and contact info
- **CSS Custom Properties** — full design token system for colors, shadows, and typography
- **Google Fonts** — Playfair Display + Inter font pairing
- **W3C Validated** — zero errors, zero warnings

## 📐 Key Concepts Applied

- **BEM Naming Convention** — `block__element--modifier` throughout
- **DRY Principle** — CSS variables defined once, reused everywhere
- **Separation of Concerns** — zero inline styles, external CSS only
- **CSS Custom Properties** — `--primary`, `--dark`, `--text-light` etc.
- **Pseudo-elements** — `::before` and `::after` for decorative details
- **Hover Animations** — `transform`, `box-shadow`, `scaleY()`, `scaleX()`
- **Document Outline** — one `<h1>`, proper heading hierarchy h1→h2→h3
